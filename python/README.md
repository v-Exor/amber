# Original CSST106 Lab 1 Python implementation

Install Python and run `python -m pip install -r requirements.txt` in this folder. The sample is the larger College of Computer Studies logo embedded in the original Word handout.

```powershell
python part1.py
python part2.py
```

Click each OpenCV window and press any key to advance. Both scripts run independently. `--no-display` saves images without opening windows. `--image "path/to/photo.jpg"` selects another image. Each script saves measurements and PNG files under its own `outputs/` subfolder. Rerunning replaces that part's saved files.

These complete scripts are preserved from the completed activity. They require desktop Python/OpenCV; GitHub Pages serves them as source downloads and does not execute them. The website runs separate JavaScript implementations in the browser. Browser parameter changes do not change these fixed example scripts.
